# ISFP 小画家动作帧素材

每个动作保存为一张完整序列图，按从左到右、从上到下的顺序读取。全部面朝右，白底，沿用 ISFP 立绘的黄色几何发型、发带、背带装、调色盘与画笔。

| 图片 | 网格 | 动作顺序 |
| --- | --- | --- |
| `idle_sheet.png` | 4×1 | 呼吸 → 眨眼与转笔 → 回到待机 |
| `walk_sheet.png` | 4×1 | 前脚迈出 → 过渡 → 后脚迈出 → 过渡 |
| `dash_sheet.png` | 4×1 | 低伏 → 蹬地 → 彩色滑步残影 → 收势 |
| `jump_sheet.png` | 4×1 | 蓄力 → 上升 → 顶点 → 下落 |
| `landing_sheet.png` | 4×1 | 触地 → 屈膝缓冲 → 起身 → 待机 |
| `light_attack_sheet.png` | 4×2 | 甩笔点刺：起手、命中、收招 |
| `heavy_attack_sheet.png` | 4×2 | 泼墨横扫：蓄力、宽幅斩击、收招 |
| `paint_projectile_sheet.png` | 4×2 | 调色盘飞镖：蘸色、投射、爆裂、收招 |
| `inspiration_dash_sheet.png` | 4×2 | 彩绘突刺：聚能、突进、斩击、收招 |
| `ultimate_sheet.png` | 4×4 | 万象泼彩狂想曲：锁定、聚能、泼彩爆发、收势 |

这些是美术关键帧。技能文档中的 13、26、34、38、52–60 帧是 60 FPS 逻辑时序；游戏中通过播放时长和判定窗口映射，不能把关键帧数量直接当成逻辑帧数。1P、2P ISFP 均接入本目录素材，其中待机使用原有呼吸动画，颜料弹使用本目录的 `paint_orb.png`。双侧共用新技能逻辑；闪避使用 1P 的 `L` 或 2P 的 `6`，无需同时按方向键。
